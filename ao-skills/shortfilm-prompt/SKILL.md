# 5 段式视频提示词方法论

改编自姊妹项目 [ai-shortfilm-prompts](https://github.com/jnMetaCode/ai-shortfilm-prompts)（MIT，同作者）的
`methodology.zh.md` 与 `cases.zh.md`。上游那份是交互式 Claude Code Skill（会向用户提问、按需读模板文件）；
这里是**单轮非交互**改编：你没有工具、也不要提问，直接按下面的规则一次写完。

核心心法一句话：**像写分镜脚本一样写提示词，不要像写文学描述。** 把场景按时间切片，
每一片交代「动作 / 镜头 / 特效 / 声音」四件事。

---

## 结构：5 段，顺序不许乱

```
1. 核心主题       ← 3-6 个 tag，用 | 分隔，从"画面类型 → 题材 → 美学风格"层层递进
2. 人物与设定     ← 面部 / 服装 / 场景，各一行
3. 氛围与画质     ← 视觉基调 / 色彩与影调 / 声音
4. 运镜规则       ← 镜头方式 / 角度 / 呼吸感
5. 分镜           ← 按秒切片，每片写清动作与声音
```

### 段 1 · 核心主题
一行标签。真实感锚点（电影级质感、超写实、杜绝游戏 CG 感）＋ 美学定调（暗黑写实、原子朋克、
废土工业、复古港风）＋ 题材 ＋ 情绪。**"电影感""高级""震撼"单独出现即为不合格**——它们不是描述，是形容词垃圾。

### 段 2 · 人物与设定
面部 / 服装 / 场景三行。服装写**质地**不写品类（"哑光黑色皮质""磨砂金属"，不是"夹克""腰带"）。
至少两处**瑕疵**：磨损、尘土、汗渍、伤痕——干净等于假。

有参考图时，把脸锁死，否则镜与镜之间人会漂：
> 面部：参照上传图片，五官、脸型、发型 100% 还原，杜绝美化。保留伤口 / 疤痕 / 瑕疵。

### 段 3 · 氛围与画质
必须写**具体摄影机型号 + 镜头型号 + 焦段/光圈** + 色调 + 光源。给 AI 一个具体的视觉锚点，
比十个形容词管用：史诗镜头用 IMAX 电影摄影机 + Panavision C 系列（35mm，f/4），
硬核科幻用 Sony Venice + Canon K-35。

色调必须在**这里**定死并逐镜一致。AI 生成视频色彩位深低，后期调色一推就断层出噪点——
**色要在提示词里修，不要指望在剪辑软件里修。**

声音固定写明，否则模型会自作主张配乐：
> 声音：无配乐，仅保留现场音。

### 段 4 · 运镜规则
写精确：相机 + 镜头、景别（远/中/近）、角度（低/高/平/过肩）、运动（推/环绕/跟/FPV）、
节奏（极慢/平稳/突发/反应式）。"围绕主角来一段有张力的运镜"是废话，
"中近景，低角度偏左 30°，顺时针环绕，极慢，带 0.1 秒反应式微抖"才是指令。

呼吸感那一句**永远带**（只有刻意要僵硬的定镜/俯拍才去掉）：
> 手持拍摄，全程保持极其轻微的、如呼吸般的镜头浮动，增强临场感。

### 段 5 · 分镜
按秒切片（0-2s / 2-4s / 4-5s……），每片写清这一秒发生什么 + 声音。

## 氛围锁定（多镜作品必做）

三镜以上的片子，【氛围与画质】**只写一次**（机身+镜头、色彩与影调、光源、颗粒/风格核心），
之后每一镜**逐字粘贴**这一段——不要每镜"稍微换个说法"。上游 `templates/project-planner.zh.md` 的原话：
"如果你发现自己在给第 4 镜写一句稍微不一样的色调描述，停——这正是剪辑型作品在后期崩色调的元凶。"
工作流里若任务给了氛围锁定块，段 3 就是它本身，不要再另写一套机身镜头色调。

## 按类型的默认运镜与节拍（段 4、段 5 的起点；任务给了类型就按这一行写）

改编自上游 `templates/genre-camera-sop.zh.md` 速查表与各题材范例（micro-drama / product-commercial 等）：

| 类型 | 开场运镜 | 收尾运镜 | 节拍与语法 | 机身参考 |
|---|---|---|---|---|
| 剧情短剧 | 冷开场直接进事件，对主角猛推的单人镜（钩子落在头 2 秒） | 悬念剪断：反转露出即停，不解答 | 正反打对话语法；写实克制表演，绷紧的下颌、一口憋住的气，不狗血 | ARRI Alexa + vintage primes |
| 产品广告片 | 产品局部特写起手（质感先于全貌） | 定镜落在产品 + 一句记忆点，不堆光效 | 节拍驱动：每拍一个动作一个产品露出；光源有动机、反光可控 | RED Komodo + Zeiss Supreme |
| 治愈日常 | 呼吸感双人/单人近景，缓慢推近 | 后拉退场，人留在光里 | 实景光、小动作、瑕疵（乱发、旧衣领）；无配乐或极轻 | Kodak 250D + Cooke S4 |
| 悬疑惊悚 | 框中框窥视（门缝/窗/镜面），缓慢潜行推进 | 定镜 + 画外音，或缓慢后拉揭露 | 负空间与低机位；信息晚给；声音靠底噪与静默切节拍 | Sony Venice + Canon K-35，漂白工艺影调 |
| 搞笑段子 | 平铺直叙的正常镜头（铺垫要"正经"） | 反转落在最后 2 秒，切得干脆 | 三拍结构：铺垫 / 加码 / 反转；表演真、镜头不抢戏 | 普通数字机 + 定焦，自然光 |
| 科幻 | 揭示升镜（从局部升到全貌） | 静守苍茫：人物停住，远处一个元素 | 尺度对比、缓慢；克制用特效，末镜不堆爆炸 | IMAX + Panavision C 系列 35mm f/4 |
| 古风武侠 | 长焦压缩的横移，人物在景中小 | 收势定格，衣袂落下即停 | 邵氏港风影调；动作靠剪点不靠慢动作；风声、布料声 | Arriflex 35 + Zeiss Standard，胶片颗粒 |
| 纪实 Vlog | 手持自然光，主观视角进场 | 收在一个真实的小动作上 | 像真的记录：抖动、过曝、路人；不设计构图，只设计瞬间 | 手持数码机 + 广角，自动曝光感 |

## 硬规则（这几条踩了就是废片，钱直接烧掉）

1. **不出现任何影视 IP 名、角色名、明星姓名。** 厂商的版权过滤会在提交这一步就拦。
   改写成**设计语言**：「钢铁侠红金战甲」→「原子朋克复古未来感红金战衣」。
2. **单镜不超过 15 秒。** 甜区按场景类型 5–15s，硬撑 30s 一镜到底会在中段画质崩坏。
   更长的序列拆成多镜，靠续写或剪辑接。
3. **不要写空泛词。** 每段都要有具体名词。
4. **控制总字数。** 写长了模型注意力散，而且会撞厂商字数上限直接提交失败。
   要压就删冗余形容词、合并相关短句、缩写场景行——不要删具体型号和分镜。
5. **结尾要克制。** 不要在最后一镜堆爆炸、光爆、粒子。安静收尾更高级：
   人停在那里，站着，呼吸，在烟尘里，配一个远处的元素（一颗划过天际的流星）。
   > 没有台词。没有爆炸。没有光芒万丈。只有身穿不完整战衣的人站在原地。
6. **多镜之间靠运动方向连贯性衔接**，不是靠对齐静帧：这一镜主体从画面右侧被推出，
   下一镜就从右侧进画。设计镜头时刻意安排出画 / 入画的边。
7. **动态镜头（变身、打斗）不垫图。** 参考图会把它自己的画风（二次元、手绘、CG 渲染）
   带进输出。参考图只用于角色/场景**连贯性**，且必须是高清无滤镜的写实素材。

## 心态

一条提示词是**一张抽卡券**，不是确定性配方。同一条提示词重抽出的结果天然不同——
高难度镜头抽 20+ 次、简单镜头 2–3 次是常态。**把功夫下在挑输出上，别指望把提示词打磨到完美。**
